# dotfiles

#### Install

```bash
bash install.sh
```

#### Setup

```bash
bash setup.sh
```

in `~/.zshrc` at the end of the file put

```bash
source "$HOME/zshrc/.zshrc"
```

build the fzf module for faster coloring

```bash
build-fzf-tab-module
```
